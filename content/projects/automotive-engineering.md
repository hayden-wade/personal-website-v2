# Engineering old cars

The next set of questions in the workshop: engine swaps, wiring and the small systems that make an old car feel properly finished.

## The M54 E30 project

I have an M54B30 engine and an E30 project that put electrical and mechanical integration in the same conversation. The useful work begins well before an engine goes into a bay: understanding the interfaces, power distribution, control signals, cooling, packaging and the changes that need documenting.

This is an ongoing project. I’m interested in making the resulting system understandable and maintainable, rather than relying on a collection of undocumented fixes.

## The check panel

The E30 check panel is a particularly appealing electronics project. It offers a small, tangible way to return to practical circuit work: understanding the original sensing behaviour, tracing the interfaces and exploring how a repair or replacement could preserve the original character of the car.

It is a project idea under development, not a completed replacement product.

## Original character, better understanding

The same thinking carries into projects such as investigating a BMW Business RDS radio, sorting out a wiring loom or repairing old connectors. I like changes that respect the car’s original design while making the system easier to live with.

ChassisWire is the documentation side of that interest. The workshop provides the questions; the software is one way of keeping the answers together.
