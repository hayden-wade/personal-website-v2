# Personal Website V2

Scaffold for Hayden Wade's personal website redesign.

## Structure

- `docs/` — design brief, architecture, design system, motion and references
- `content/` — about, experience, projects and writing
- `public/images/` — imagery organised by section
- `src/` — website source code (implementation to come later)

The repository currently contains the agreed content and design scaffold only. The full website implementation will be added later.
