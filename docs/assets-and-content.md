# Assets and content

## Text

The seven E30 Markdown articles were adapted from **E30 Respray Blog Series – Drafts.docx**, supplied for this website. The document contains two draft sets; the later `POST 1`–`POST 7` set was used. Photo prompts and publishing notes were removed. Photographs were visually checked and inserted near relevant sections. Approximate remembered costs remain approximate; the unverified precise receipt subtotal and external storm-report summary were omitted.

The original Word document remains the historical source; the Markdown files are now the editable publication copy. The optional one-time import script is retained for traceability; rerunning it will replace the publication edits and photograph placements, so do not use it for routine updates.

Home and project summaries use the supplied professional and project background. Ongoing projects are labelled accordingly. Personal medical, relationship, mortgage and other unrelated information is excluded.
