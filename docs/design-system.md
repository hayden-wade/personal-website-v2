# Design System

## Colour palette

- Main background — `#D6D1C6` — warm stone
- Alt background — `#C7C1B5` — darker warm stone
- Primary text — `#1B1D1B` — graphite-black
- Secondary text — `#5F625D` — warm technical grey
- Borders / lines — `#AFA99E` — muted stone
- Accent — `#A45A3A` — burnt copper
- Technical accent — `#39423E` — deep green-grey
- Light text — `#ECE6DB` — warm ivory

## Typography

- Display / large statements: editorial serif
- Body / navigation / UI: clean sans with a feel similar to the Constance Souville reference
- Body copy should be generous, clean and readable rather than tiny portfolio text

## Visual principles

- Warm, modern, technical
- Editorial rather than corporate
- Restrained accent usage
- Full-colour photography
- Strong negative space
